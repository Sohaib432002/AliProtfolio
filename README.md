# Ali Haider — Web & Mobile Developer
Live Link: https://ali-portfolio-mocha.vercel.app/
Personal portfolio for **Ali Haider**, a Computer Science graduate in Rawalpindi, Pakistan, building role-based web platforms and React Native mobile apps.

Live stack: Next.js, TypeScript, Tailwind CSS, React Three Fiber, Motion.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```
